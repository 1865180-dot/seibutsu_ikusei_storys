# 道の駅の名物づくり 〜ミニトマト編〜（© Irie Kanji）

中2 技術「C 生物育成の技術」用のシナリオ（ノベル）型ゲーム。1班（または1人）1台のChromebook、1回 約25〜30分。

## ファイル
- `index.html` … ゲーム本体（これ1つで動く。画像ファイル不要）
- `Code.gs` … 記録をスプレッドシートに送る Apps Script の例

## 公開のしかた（今のシミュレーターとは別のリポジトリにしてください）
1. GitHub で新しいリポジトリを作り、`index.html` をアップロード
2. Settings → Pages → Branch を `main` / `(root)` にして保存
3. 表示された URL を生徒に配る

## 提出（スプレッドシート）を使うとき
1. `Code.gs` をスプレッドシートの Apps Script に貼り、ウェブアプリとしてデプロイ
2. `index.html` の先頭近く `SUBMIT_URL: ''` に、ウェブアプリのURLを貼る
- 未設定のままでも動きます。その場合、最後の画面に「記録の文章」が出て、コピーして提出する形になります。
- 組の数・番号の最大は `CLASSES` / `MAX_NUM` で変えられます。

## 先生用：すべての結末を確認する
URLのうしろに `?teacher=1` をつけると、左上に確認用ボタンが出ます（ステージ1／ステージ2／各場面／各結末へジャンプ）。
生徒に配るURLには付けないでください。

## 流れ
タイトル → 登録（組・番号・主人公名） → 導入 → ステージ1（社長だけの意見で失敗） → ステージ2（10場面、3人の意見をくらべて選ぶ） → 評価S〜D・結末 → 3人のコメント → ふりかえり・提出（またはステージ2から再挑戦）

## 10場面（ミニトマト）
品種 → 土づくり → pH → 元肥 → 水やり → わき芽かき → 害虫・病気 → 台風 → 収穫のタイミング → 売り方
場面ごとに「学習メモ」（団粒構造・pH・肥料の三要素・IPM・追熟・地産地消 など）が出ます。
前の選択があとの場面に響くところが3か所あります（土→元肥／わき芽→台風／水やり→収穫）。

## 評価のしくみ
4つのメーター（収量・品質・コスト・環境）を、「もうけ・量」「品質」「環境」の3つの軸にまとめ、
合計点と「かたより」で S〜D を決めます。どれか1つに寄ると、評価の上限が下がり、かたよりに合った結末になります。
