# 写真フォルダ

このフォルダに下の名前で写真（.jpg）を置くと、ゲームの「資料カード」の絵が写真に替わります。
ない写真は、絵のまま表示されます（エラーにはなりません）。横長（4:3くらい）がおすすめです。

|---|---|---|

| sekkai.jpg | 3 土のpH | 苦土石灰 |
| kasei.jpg | 4 元肥 | 化成肥料（粒） |
| aburakasu.jpg | 4 元肥 | 油かす |
| wakime.jpg | 6 わき芽かき | 実物のわき芽（葉のつけ根から出ているところ） |
| aburamushi.jpg | 7 害虫・病気 | アブラムシ |
| konajirami.jpg | 7 害虫・病気 | コナジラミ |
| tentoumushi.jpg | 7 害虫・病気 | テントウムシ（天敵） |

自分で撮った写真か、使用が許可されている写真を使ってください。
出典を表示したいときは、index.html の `PHOTO_CREDITS: {}` に `{ aburamushi: '撮影：○○' }` のように書きます。
